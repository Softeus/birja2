# Экран «Пульс рынка + тепловая карта MOEX»

Интерактивный прототип для собеседования в Московскую биржу. Один экран: тепловая карта 44 бумаг IMOEX + объяснимый индекс настроений.

## Запуск

```bash
pnpm dev          # http://localhost:3000/heatmap
```

Живые данные — из MOEX ISS (BFF `app/api/market`). Офлайн — mock-режим на сохранённом снимке `lib/market/fixtures/market.snapshot.json`.

## Что на экране

| Зона | Что показывает |
|---|---|
| Шапка | `PulseGauge` (индекс настроений 0–100, зона), IMOEX/RVI, кнопка «Разобрать индекс» |
| Разбор | 4 `FactorCard` (динамика, волатильность, широта, оборот) со слайдерами |
| Карта | треемэп: 44 плитки, 9 секторов; площадь = капитализация, цвет = Δ% за день |
| Панель | детали выбранной бумаги + спарклайн 1D |
| Статус-бар | число бумаг, время среза, задержка, источник |
| StateLab | ручное переключение состояний и источника live/mock |

## Состояния (8)

`loading` · `live` · `stale` · `closed` · `error` · `empty` · `index-missing` (индекс не рассчитан) · `simulation` (слайдер сдвинут).

## Данные

- Все числа — из ISS или посчитаны из него. Синтетика — только mock-снимок.
- Задержка открытого контура ~15 мин показывается, а не скрывается.
- Методика индекса `pulse-1` (равные веса) видна на экране.

## Дисциплина ДС

- Цвета/размеры — только токены (`bullish-1..3`, `bearish-1..3`, `neutral`, `sentiment-*`, `data-live/stale`).
- Новые компоненты экрана — в `components/heatmap/*`; слайдер — shadcn/radix (`components/ui/slider.tsx`).
- Без `#hex`, без `bg-<палитра>-<число>`, без инлайновых `font-size`.
